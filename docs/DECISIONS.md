# Decisions

- `runtime/` owns C; `training/` and `datagen/` own Python; only `contract/` bridges them, so no implementation imports another.
- `datagen/` is a first-class layer that depends only on the dataset contract and third-party packages; runtime and training never import datagen.
- Each project's lock and synced environment is the layer boundary; an AST import check, which rejects unresolvable dynamic imports and path changes, is the second line.
- The model contract is distribution `strata-contract`, import `strata_contract`; the dataset contract is `strata-dataset`, import `strata_dataset`, in `contract/dataset/`.
- Model contract v1 fixes tensor interfaces, normalization, padding, color and depth semantics; C rejects incompatible manifests and ONNX metadata before inference.
- DP2 H+ runs at native resolution with bottom/right replicate padding to 32; DP2 does not use Depth Pro 1's resize pipeline.
- Metric depth is `f_px / (original_width * inverse_depth)`; zero inverse remains positive infinity.
- Export opset 23 Attention and tensor-valued RoPE dimensions to preserve memory-efficient attention and arbitrary portrait/landscape inputs.
- Learned operations run FP16 to bound memory and public tensors are float32; final projection, encoder taps and the 1/32 decoder branch run float32: the last tap exceeds FP16 range.
- Compare export parity at matching PyTorch precision; report stock bfloat16 differences separately because changing precision is not export error.
- Parity gates every image alike vs FP16 PyTorch: p99.9 1%, max 5% beyond 2 px of a log step >0.3, median and signed bias 0.25%, focal 0.1%; no per-image exemptions.
- Against an FP32 oracle, native median and |signed bias| may exceed PyTorch FP16's own by 0.2 pp, the most PyTorch moves under 1-fp16-ulp input perturbations.
- Scene-linear EXR receives exposure and continuous sRGB conversion for inference only; deep RGB preserves source values and alpha is always one.
- Shoulder and sRGB math use double precision, rounded once to float32 before ImageNet normalization; encoder_input parity is bit-identical (atol 0).
- Negative and NaN scene-linear input map to zero; +inf maps to one and -inf to zero; each result counts non-finite pixels.
- Scanline RGB EXR and already-oriented 8-bit PNG/JPEG are P0 inputs; reject tiled/deep/subsampled EXR rather than guessing a conversion.
- `strata_run` infers one frame; temporal inference will be a separate stream API rather than a frame count on this call.
- Filled outputs take a zeroed or previously filled object, free its old contents first and hold nothing on failure, so hosts reuse them per frame.
- Results keep only the network output; camera-Z and inverse metres are derived from it and the resolved camera by accessors and writers.
- Focal source is explicit: provided needs positive fx/fy, estimated takes zero intrinsics and is resolved by the model; unset is rejected.
- Exports bake ORT basic-level transforms, stride==kernel ConvTranspose as 1x1 Conv+DepthToSpace and fused RotaryEmbedding.
- A separate, lazy `.fov.onnx` keeps automatic focal estimation optional and avoids paying its session cost when focal is supplied.
- Deep scanline output uses Core's raw chunk C API and uncompressed float32 samples; OpenEXR 3.5.3's default deep packer is still a stub.
- Flat output uses lossless ZIP with `Z` and `network_inverse_depth`; fake deep has exactly `R G B A Z ZBack`, one sample/pixel and `ZBack == Z`.
- Writers create a sibling temporary file and rename it over the target, so readers never see partial output.
- Explicit providers fail when unavailable; `auto` falls back to CPU and reports why through `strata_fallback_reason`; the library never prints.
- CUDA and the PyTorch oracles disable TF32 so float32 operations keep IEEE precision; allocator, arena and threads stay at ONNX Runtime defaults.
- TensorRT, CoreML and DirectML are out of scope until each lands with a test and a measurement.
- The CLI refuses outputs inside the model's directory instead of parsing ONNX for external data, which ONNX Runtime confines to that directory.
- Keep merged deep, beauty and layers on every frame; delete raw EXRs and NPY sidecars only after durable acceptance verifies merged rebuilds the packed targets, making raw redundant.
- Acceptance binds raw proof, retained digests, algorithm versions and raw-only limits; retired QA runs fresh, refusing changed raw-only policy; `test_retired_qa` checks this.
- Identity gates: unlabelled visible coverage/pixel <=2e-4; declared/labelled visible coverage >=0.99995 (empty=1); raw ID counts only report; test_retired_qa checks merge invariance.
- Compositing, partial coverage and sky QA merge raw first, sharing retired definitions; raw depth, role excess and raw equivalence checks bind policy in acceptance receipts.
- Training, evaluation and baselines never align predicted depth to GT; learn and score metric scale directly against synthetic deep truth so scale errors remain visible.
- K-slot visible coverage is a simplex with opaque terminal alpha, closing holes by construction; check: test_head_coverage_is_exactly_one.
- Gate GT-opaque interior leakage at 0.001; brightness bins use 1.4 and 0.04; checks: test_behind_surface_leakage, test_count_aware_brightness_gate.
- Detach alpha only in per-layer colour supervision; preserve colour space and composite gradients; check: test_layer_colour_does_not_steer_coverage_but_composite_still_does.
- Depth Pro 2 encoder stays frozen to train only downstream weights; test_encoder_stays_frozen checks parameters and training mode.
- Fable shoulder uses gain 0.72, knee 0.6, span 0.4 and sRGB, preserving midtones and compressing HDR; test_fable_fixed_points_and_float_cache fixes values.
- Exposure is fixed per shot, never inferred per frame; --exposure is an additive stop override; test_exposure_is_fixed_across_frames_and_crops checks invariance.
- Encoder input stays float32 end to end; reject old target/feature caches, never quantize; encoder_input parity and float-cache checks enforce it.
- No second encoder pass: frozen features run once per frame; test_native_denoised_extraction_persists_matching_inference_image_and_rejects_changes counts pyramid calls.
- Sweep reference is retained K-layer point deep; re-measure against merged deep on real 0.5.0 shots; check: test_pooled_regions_preserve_directions_and_ignore_other_contestants.
- Sweep integrates signed coverage differences in log metres without normalisation; test_opaque_sweep_is_log_distance_and_signed fixes scale and directions.
- Sweep bounds use this pixel's GT/prediction minimum Z through 200 m; sky maps to 200 m; test_opaque_sweep_is_log_distance_and_signed fixes the far clamp.
- Weight pixel-pooled edge and opaque-interior sweeps 50/50; revisit during training; check: test_pooled_regions_preserve_directions_and_ignore_other_contestants.
- Before any gate pass select least overall leakage and label no production candidate; test_ood_validation_retains_best_and_stops_at_patience_without_resetting_on_resume checks it.
- Any new validation sweep best resets patience; flat/rising scores stop after patience checks; test_ood_validation_retains_best_and_stops_at_patience_without_resetting_on_resume checks stop steps.
- Exact score ties prefer lower overall leakage then earliest step, independent of arrival; test_checkpoint_selection_is_order_independent_and_slot_mae_is_diagnostic checks ties.
- Brightness buckets pool pixels: below 250 are not evaluated; otherwise limit=max(0.001,25/n); overall always gates at 0.001; test_count_aware_brightness_gate fixes boundaries.
- Report premature occlusion before the visible GT surface without gating; test_premature_occlusion_is_report_only_and_gt_surface_is_visible checks it.
- Validation brightness comes from GT beauty, not denoised model input; test_validation_brightness_uses_gt_not_denoised_model_input fixes the source.
- Sweep opaque interior includes sky at the far clamp; leakage requires a finite GT surface; test_sky_interior_is_scored_and_invalid_prediction_depth_is_not_sky checks sky.
- Selection v3 rejects older resume history after sweep weighting and stopping changes; test_ood_validation_retains_best_and_stops_at_patience_without_resetting_on_resume omits the saved key.
- Production eligibility requires leakage pass and sweep strictly below frozen DP2; test_ood_validation_retains_best_and_stops_at_patience_without_resetting_on_resume checks no-candidate runs.
- Freeze and log one DP2 single-opaque-layer sweep per run on the same validation frames; test_dp2_baseline_is_single_opaque_layer_from_frozen_metric_depth checks metric depths.
- Opaque sweep interior requires total coverage >=0.999 outside the edge band; test_opaque_interior_threshold_is_inclusive_0999 fixes the inclusive threshold.
